# R3.1 — Measurement Enablers

Status: ✅ **live accepted 2026-08-26.** The three tools remain `additive-preview`; the
measurement phase made no separate stability-promotion decision.

R3.1 adds only the three consumer-neutral operations needed to make the already-accepted R3 style/component gates measurable.  It does **not** add style creation, remote-style import, component authoring, or a generic document mutation surface.

## Public additions

| Tool | Boundary | Refusal-before-write rule |
| --- | --- | --- |
| `create_group` | Creates one native group from explicit local scene-node IDs under an explicit compatible parent. | Reject empty, duplicate, cross-page, ancestor/descendant, missing, non-container, and invalid-index inputs before calling `figma.group`. |
| `set_range_font` | Applies one exact `{fontFamily,fontStyle}` face to a non-empty `[start,end)` range on one `TEXT` node. | Reject non-text, unsupported range API, invalid/out-of-bounds range, and unloadable requested face before the range setter. |
| `set_fill_style` | Attaches an exact local paint-style ID to one supported node, or clears that attachment with `styleId: null`. | Reject missing/non-local IDs, unavailable async attachment API, and nodes without the fill-style surface before the async setter. |

All three are `additive-preview`; existing stable tool inputs and result shapes are not repurposed.  `set_fill_style` only changes the node's style attachment. It neither creates nor edits a style resource, and it deliberately does not import or attach a remote/library style.

## Gate protocol

Every R3.1 live scenario requires both a current runtime pin and the explicit acknowledgement `--disposable-target=true`. The target must be an owner-confirmed disposable Figma file. A successful offline build or a regenerated runtime pin is not evidence that a live scenario ran.

| Scenario | Platform fact being measured | Control and independent observation | Cleanup / unmeasured fallback |
| --- | --- | --- | --- |
| Group ownership for constraints | A group created by the native API can own a controlled child whose constraints are then measured inside a frame. | `live-r3.1-group-gate.mjs` creates the group, proves duplicate-member refusal before writing, independently reads its hierarchy/geometry, and applies a constraint to its child. | Delete the scratch page in `finally`; do not accept a hand-made group or an unresolved hierarchy/geometry reading. |
| Mixed-font range mutation | An exact range setter mutates only the requested character interval after loading its requested face. | `live-r3.1-range-font-gate.mjs` creates its own text/control pair, proves invalid-range and absent-font refusal, and observes mixed state through the existing node-scoped tool. | Delete the scratch page in `finally`; invalid range or font refusal must leave the text unchanged. |
| Local paint-style attachment and detach | A local style can be attached through the async style API and a subsequent fill write has a measurable attachment result. | `live-r3.1-fill-style-gate.mjs` gets the local inventory, attaches one exact returned ID, uses `set_fill` as an independent observation, and proves explicit null detach. | Delete the scratch page in `finally`; if the file has no local paint style, report `unmeasured` rather than substituting a remote style or treating absence as a pass. |

## Acceptance boundary

The R3.1 code change necessarily changes the generated contract/runtime fingerprint. Therefore all historical live-gate pins become historical evidence, not proof for this runtime. Before R3.1 is accepted, the three updated gate scenarios and the prior live gates required by the release policy must be rerun against the published runtime in an explicitly confirmed disposable target. No unknown or production Figma document is an authorized target.
